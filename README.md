# Cloud File Storage System

## Project Overview
Cloud File Storage System is a web-based application that allows users to securely store and manage files online. Users can register, log in, upload files, view uploaded files, download files, and delete files through a simple and user-friendly interface.

## Features
- User Registration
- User Login & Logout
- Secure File Upload
- View Uploaded Files
- Download Files
- Delete Files
- Dashboard with Total Files Count

## How to Run the Project

### Step 1
Download or clone the project from GitHub.
### Step 2
Open the project in IntelliJ IDEA.
### Step 3
Configure Apache Tomcat 9 in IntelliJ IDEA.
### Step 4
Build and run the project.
### Step 5
Open the application in your browser.
Example:
http://localhost:8080/CloudFileStorage/
### Step 6
Register a new account.
### Step 7
Login using your credentials.
### Step 8
Upload files using the Upload File option.
### Step 9
View uploaded files.
### Step 10
Download or delete files as required.
